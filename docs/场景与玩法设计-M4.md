## 1. 目标与原则

### 1.1 目标

1. 场景从"一个空盘子"升级为一个**有生命感的小生态**：有地形（河流）、有植被（树木）、有天（太阳/月亮/星星与昼夜循环）；
2. 每一项用户交互都必须有**可感知的因果反馈**：投喂能看到果蝇凑近并吃掉、聚光能看到光斑与趋光路线、吹风能看到树木摇晃与果蝇的反应；
3. 引入最轻量的"游戏性"：果蝇有生命（饥饿扣血、进食回血、被捕食即死亡重生），捕食者（青蛙）构成威胁，让用户产生牵挂。

### 1.2 设计原则（延续既有架构）

- **所有动态元素都是 world.glb 里的命名节点**，生成脚本 `tools/gen_world_glb.mjs` 扩展产出，运行时按名字 DFS 查找后用代码驱动变换（沿用 fly/wing_left 的成熟模式）；
- **行为层保持纯逻辑**（FlyBrain 扩展），渲染层只消费姿态；新增生态元素的状态机同理分层；
- **性能红线**：单帧驱动变换的节点数 ≤ 40；所有动画用正弦/噪声函数程序化驱动，不引入骨骼动画；总面数 < 8 万三角面。

## 2. 场景地形与元素设计

### 2.1 地面与河流

| 元素 | 建模方案 | 位置约束 |
|---|---|---|
| 地面 | 现有圆盘（r=5.5）保留，底色改为草地绿-土黄双色（两个同心圆盘叠放：外圈草地、内圈活动区） | y=0 |
| 河流 | 一条贯穿场景的**弧形水带**：圆环 geometry（外半径 6.8、内半径 5.2 的一段弧，约 70°），水面 y=-0.02（略低于地面），半透明蓝材质（baseColor #3F7FD9 alpha 0.75，材质 blend 开启） | 沿场地东北→西南弧线 |
| 河岸 | 水带两侧各一圈细长"鹅卵石"椭球（12~16 颗，灰白色，随机缩放） | 紧贴水带边缘 |

**行为规则（"水只在河里"）**：
- `FlyBrain.applyBoundary()` 增加水域判定：河流弧段用极坐标描述（角度区间 + 半径区间），果蝇坐标落入该区域时视为"临水"；
- 临水时果蝇**不会走进水里**（水域对步行是障碍）：转向逻辑追加"背离河心的斥力"，把河当作一堵弧形墙；飞行状态允许掠过水面（高度 y ≥ 0.3）；
- 临水饮水彩蛋：果蝇在河岸边缘驻留 2 秒触发"饮水"小动画（头部下压 15°，复眼贴近水面，3 秒后离开）——作为 Feed 的姊妹状态（`Drinking`），不新增驱动力，纯彩蛋。

### 2.2 树木 ×3

| 属性 | 设计 |
|---|---|
| 建模 | 每棵树 = 树干（圆柱，棕色，h≈1.2，上细下粗）+ 树冠（2~3 个错位堆叠的椭球，深浅两种绿色）+ 可选果实（树冠表面 3~5 颗小红球，兼作食物彩蛋） |
| 节点结构 | `tree_0/1/2`（根部，位于地面）→ `trunk`（树干子节点，**摇晃驱动点**）→ `crown`（树冠子节点，二级摇摆） |
| 位置 | 场地边缘外一圈（半径 5.0~6.5），不遮挡果蝇活动区；1 棵在河岸边（倒影彩蛋见 2.3） |
| 摇晃动画 | **风吹时才摇**：全局风力 `windStrength`（0~1）> 0 时，树干绕根部做 `rotation.z = A·sin(t·f)·windStrength` 摆动，A≈4°、f≈1.2Hz，三棵树相位错开；树冠二级摆动幅度 ×1.6、相位 +90°，形成"由下至上递增的柔顺感"；无风时树冠做 0.5° 微颤（呼吸感） |

### 2.3 太阳、月亮与星星（昼夜循环）

**昼夜状态机**（`EnvironmentController`，渲染层新类，纯视觉不影响行为层除光照档位外）：

| 时段 | 占比（一轮 240 秒） | 太阳位置 | 天空 | 光照 |
|---|---|---|---|---|
| 白天 | 50% | 沿大圆弧从东（+X 远端）升到顶再落西 | 亮蓝天（clearColor 动态插值 #87CEEB→#FFD9A0） | 平行光强度 1.0，色温暖白 |
| 黄昏 | 12% | 太阳落到西地平线 | 橙红渐变 #FF9A5A | 强度 0.5，色橙 |
| 夜晚 | 26% | 太阳落到地平线下，月亮升起（对角） | 深蓝 #0B1026，星星显现 | 强度 0.15，色冷蓝 |
| 黎明 | 12% | 月落，太阳将升 | 粉蓝渐变 | 强度 0.4 |

实现要点：
- **太阳**：一个发光圆盘（emissive 橙黄），父节点 `sun_pivot` 在场景原点，绕 Z 轴做 360°/240s 匀速旋转，太阳圆盘挂在 pivot 半径 9 处——天然实现"东升西落"；月亮 `moon_pivot` 反相 180° 挂同样的 pivot 链（或独立 pivot 反相旋转）；两者始终只有一个在地平线上方（visible 切换）；
- **星星**：25~35 颗小三角片（复用 M2 brain 点云的三角形做法），随机分布在天穹半球（半径 12，y>2），统一挂 `stars` 节点下，`stars.visible` 由夜晚时段控制，同时整体做缓慢自转（0.5°/s 模拟天球）；个别星星做 1~2Hz 的亮度闪烁（scale 微缩放 0.9~1.1）；
- **clearColor 动态插值**：SceneManager 每帧根据时段计算 `camera.clearColor`（时段关键色之间线性插值）——若引擎 clearColor 不生效（M0 已知问题），备选方案：一个半径 12 的大反转球壳（cullMode FRONT）作为天空穹顶，顶点色或分段材质做渐变；
- **与行为联动**：夜晚 = 果蝇 `lightLevel=0` 语义（休息阈值 0.4、无趋光），用户手动开"聚光"可短暂创造局部亮区（见 3.3）。

### 2.4 元素总表（world.glb v2 新增节点清单）

| 节点名 | 类型 | 数量 | 驱动方式 |
|---|---|---|---|
| river / river_bank_stone_i | 静态 mesh | 1 / 12 | 无（水面微波见 3.4） |
| tree_0..2 / trunk_i / crown_i | mesh 节点 | 3 组 | 风摆 rotation.z |
| sun_pivot / sun | 轴心+圆盘 | 1 组 | 匀速旋转 |
| moon_pivot / moon | 轴心+圆盘 | 1 组 | 反相旋转 |
| stars / star_i | 组+三角片 | 1 / 30 | 夜显 + 慢自转 |
| fruit（树冠果实） | 小球 | 9 | 静态彩蛋 |

面数预算：河流+石块 ≈ 1.2k、树 ×3 ≈ 2.4k、日月星 ≈ 0.8k，合计新增 < 5k，安全。

## 3. 交互效果深化（对应当前"感知不到反馈"的问题）

### 3.1 投喂 → 完整进食链条

现状问题：食物出现后果蝇虽然会去吃，但"吃"这个动作没有可视证据。

设计（四级反馈）：
1. **食物出现**：投放瞬间食物从 y+0.6 处弹跳落地（0.4s 二次弹跳缓动），同时状态行文字提示「发现食物！」；
2. **觅食跟踪**：Seek 状态时在果蝇与食物之间画一条**淡色虚线路径**（地面上方 0.02 的一串 6 个小点节点，依次明灭指示方向——用节点 visible 轮流开关模拟流动）；
3. **进食动作**：进入 Feed 状态后果蝇**头节点（head）下压 20°、周期性小幅点动**（1.5Hz，模拟舔食），身体随进食节拍微微起伏；同时食物以进食进度同步缩小+下沉（现有逻辑保留）；
4. **吃饱反馈**：食物吃完时原地冒出 3 个绿色"+"小片上浮消散（0.8s），果蝇腹部短暂发亮（abdomen 材质 emissive 0.3→0，1s 衰减），饥饿驱动力肉眼可见地下降。

实现注：头下压需要 head 节点可独立旋转——gen_world_glb.mjs 中给 head 增加轴心节点 `head_pivot`（旋转中心在颈部）；"+"特效预置 3 个隐藏节点（plus_fx_0..2）。

### 3.2 聚光 → 光斑与趋光的可视化

1. **光斑本体增强**：光斑从静态圆盘升级为"呼吸光斑"——scale 在 0.94~1.06 间以 0.8Hz 正弦呼吸，emissive 强度同步微调（若材质 emissive 不可运行时改，改为两层圆盘交替 visible 闪烁）；
2. **果蝇趋光姿态**：Phototaxis 偏置生效时（Wander 中朝向光斑），果蝇翅膀做 2Hz 低幅振翅（介于 idle 与 fly 之间，表现"兴奋"）；
3. **到达光斑**：果蝇进入光斑半径 0.5 内后原地做"晒太阳"动作（静止 + 翅膀展开 15° 停留 2~4 秒，翅膀 rotation 固定展开角），期间好奇驱动力快速上涨——把"趋光"闭环成用户可读的行为。

### 3.3 吹风 → 风场可视化

现状：吹风只影响果蝇，场景无变化，用户感知不到"风"。

设计（风吹到哪，哪里动）：
1. **全局风力曲线**：`gust()` 产生 1.8s 风力包络（快起 0.2s → 平台 → 缓落 0.6s），`windStrength` 实时输出给渲染层；
2. **树木摇晃**（见 2.2）：三棵树全部随风摆动——这是风最直观的视觉锚点；
3. **风线粒子**：预置 6 条"风线"节点（细长半透明白色扁条，长 0.8），风吹时从上风方向掠过场景（0.9s 内横穿，依次延迟 0.1s），结束时隐藏；
4. **果蝇反应分级**（行为层已有）：弱风趴伏（翅膀收拢贴背 + 身体贴地）；强风惊吓逃离 + 起飞；飞行中遇强风被"吹偏"（航向附加下风向偏置 15°/s，持续风期）；
5. **河面涟漪**：吹风时河面水色透明度轻微波动 + 3 个白色涟漪圆环从风落点扩散（复用"+"特效的节点轮换思路）。

### 3.4 常态氛围（无交互时的生命感）

- 河面常态微波：水面节点 y 做振幅 0.004 的 1Hz 起伏 + 材质透明度微呼吸；
- 蝴蝶/蜻蜓彩蛋（可选，M4 后期）：一只 4 翅小飞虫沿固定 8 字路径巡场，果蝇对它无视（纯氛围）。

## 4. 玩法系统设计

### 4.1 果蝇生命系统（HP）

| 项 | 设计 |
|---|---|
| 生命值 | HP 0~100，初始 100。UI：状态行增加心形进度（❤62），大脑小窗同步 |
| 扣血 | 饥饿=100 时 -2/秒；被青蛙捕食命中一次 -50；风吹进河（若边界逻辑失效落水）-30/秒 |
| 回血 | 进食 +18/份；饮水彩蛋 +5；晒太阳（光斑内）+1/秒 |
| 死亡 | HP≤0 → 新状态 `Dead`：果蝇翻面躺地（rotation.x=180°），翅膀摊开，场景变灰 10%（light intensity ×0.9） |
| 重生 | 死亡 5 秒后原点重生：淡入 + HP=60 + 全驱动力重置，死亡次数计数（About 页可查"这只果蝇的一生"） |

### 4.2 捕食者：青蛙 ×1

| 属性 | 设计 |
|---|---|
| 定位 | 唯一威胁源，制造"守护果蝇"的牵挂感；**不可杀死**（它是生态一环） |
| 建模 | 低多边形青蛙：椭球身体 + 两个大眼球（凸起球）+ 四条折腿（圆柱段）+ 舌头（细长圆柱，**攻击时才可见/伸出**）；蹲坐在河边固定点（河岸东侧） |
| 待机 | 静止蹲坐，每 6~10s 做一次"鼓腮"（身体 scale.y 1.0→1.12→1.0，1s）+ 偶尔眨眼（眼皮薄片 visible 闪烁 0.15s） |
| 索敌 | 果蝇进入**警戒圈**（距青蛙 < 2.2）且青蛙"饥饿冷却"结束（进食一次后 40s 内不再攻击，避免劝退）→ 进入蓄力 |
| 蓄力 | 0.8s：青蛙下蹲（scale.y 0.85）+ 眼球转向果蝇方向——这是给用户的"预警信号"，此时点"吹风"可把果蝇吓走（**救援玩法**） |
| 攻击 | 舌头弹出：舌头节点从嘴部沿果蝇方向快速伸长（0.18s 内 length 0→距离），命中半径 0.35 → 果蝇 -50 HP 并被"粘"住拖向青蛙 0.3s，然后挣脱弹开（果蝇直接进入 Startle+起飞）；未命中 → 舌头收回，青蛙冷却 8s |
| 死亡边界 | 果蝇 HP≤0 的原因若是捕食，死亡文案区分「被青蛙捕获」 |
| 节点 | `frog`（root，含 body/eye_l/eye_r/tongue/leg_i 子节点），tongue 的伸缩用 scale +朝向四元数实现 |

### 4.3 更多生物（M4 后期可选池，按优先级）

| 生物 | 作用 | 要点 |
|---|---|---|
| 蜻蜓 | 中立飞行者，与果蝇抢食（食物被它先到就吃掉） | 沿随机航点飞行，复用果蝇翅膀驱动代码 |
| 蚂蚁 ×3 | 地面清道夫：把没吃完的食物碎屑搬走 | 直线往返 + 背驮食物小块 |
| 萤火虫 ×5 | 夜晚专属氛围+玩法：夜晚发光（emissive 闪烁），果蝇夜晚会被吸引（趋光目标自动换成最近萤火虫） | 白天 visible=false |
| 第二只果蝇 | 拓展社交（M5+）：争食、追逐 | 复用整套行为层实例化 |

### 4.4 玩法循环（用户视角）

```
观察（它在干嘛？）→ 干预（投喂/聚光/吹风/触碰）→ 看到因果反馈
     ▲                                        │
     │            青蛙袭击 = 危机事件           │
     └──── 救援（吹风吓跑青蛙时机）←── 危机提醒（蓄力动画+状态行「⚠ 青蛙盯上它了」）
```

- **危机提醒**：青蛙进入蓄力时状态行变红显示「⚠ 天敌！」，用户有 0.8s 反应窗口（吹风救/不管）；
- **成就轻量版**：连续喂养 3 次（不落场即吃）→ 状态行出现「信任+1」；被吃 0 次存活一轮昼夜 → 「平安一夜」。

### 性能与开关

- 新增可驱动节点 ≈ 60 个（含特效），仍在 ≤40 个/帧变换的预算边缘——**特效节点按需激活**（风线/涟漪/加号只在事件期间可见并参与变换），常态每帧驱动 ≤ 25 个；
- 设置页新增「昼夜循环」「青蛙」两个开关（默认开），关闭时对应节点隐藏、逻辑旁路，保证低端机可玩。

## 6. 验收标准（M4）

1. 一轮昼夜循环（4 分钟）完整可感：太阳东升西落、夜晚星星月亮、天色与光照同步变化；
2. 吹风时至少 2 棵树同步摇晃 + 风线掠过 + 果蝇分级反应，三者同帧发生；
3. 投喂全链条可观察：食物弹跳落地 → 虚线路径 → 果蝇低头点动进食 → 食物缩小消失 → "+"特效 → 饥饿下降；
4. 河流存在感：果蝇步行永不入水，飞行可过河；饮水彩蛋可触发；
5. 青蛙完整闭环：待机鼓腮 → 蓄力预警（状态行变红）→ 舌头攻击命中/落空 → 冷却；果蝇 HP 随事件增减，死亡翻面、5 秒重生；
6. 深浅色模式下所有页面（设置/关于/场景 HUD）无刺眼违和配色；
7. 全程 ≥30fps（快照法粗测），无新增崩溃。
